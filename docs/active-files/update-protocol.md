# Registry update protocol

Add, move or mark files in the matching area document in this directory. Preserve usage and dependency annotations. Update the date in the root ACTIVE_FILES.md index after every create/delete/move. Mark removals with the date and the reason; do not silently erase their history.

Use git ls-files for a tracked-file inventory and search every docs/active-files/*.md document when checking registration coverage. The historical statistics document is context, not an authoritative current total. Any numeric audit must state its included paths, excluded paths and date.
