Art File Definitions

Picture files

.PNGPortable Network Graphic

Used for website development. Transparent background.

.JPGJoint Photographic Group

Used for digital images across the internet and social media.

.PSDPhotoshop Document

Created in Adobe Photoshop with layers. All layers are editable and can be saved in layers or combined into a single image.

Vector files

.AIAdobe IllustratorVector

Created in Adobe Illustrator with layers. All layers are editable and can be saved in layers or combined into a single image.

.CDRCorelDRAWVector

Created in CorelDRAW with layers. All layers are editable and can be saved in layers or combined into a single image.

.PDFPortable Document File

Sends documents and text formatting independent of any application. If saved and sent as editable, it is vector art.

.EPSEncapsulated PostScript

An older print standard. It is vector based and works for the most part, but is not an ideal vector file.
